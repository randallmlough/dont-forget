Implementation Notes: Stop Household Sync Workflow Cleanly

Design Decisions

  • Home owns an explicit Household sync coordinator handle for each rendered Household data source so Home cleanup and sign-out can stop sync before closing local Household data.
  • Active List remains the UI surface that subscribes to coordinator status and starts foreground lifecycle work while it is mounted.

Deviations From Spec

  • None yet.

Tradeoffs Considered

  • Keeping the coordinator entirely inside Active List was rejected because Home sign-out and cached-to-fresh replacement can close Household data before Active List effect cleanup runs.
