# Integration-First Test Suite Rewrite Audit

Date: 2026-05-29

Classification rules:

- `keep`: already proves the behavior at the right boundary, or is a focused unit/race/adapter test where fakes are deliberate.
- `convert`: product behavior currently relies on mocked app-owned collaborators and should move to an integration harness. If marked converted, the replacement landed in this rewrite slice.
- `delete`: implementation-detail coverage that should be removed only after equivalent or stronger integration coverage exists.

## Deletion bar

No test files were classified `delete` in this slice. The first rewrite removed the legacy `db/fixtures/session.ts` helper, not product behavior coverage. Any future deletion must name the stronger integration test that preserves the same user/domain outcome before the mocked test is removed.
