Implementation Notes: Network-Aware Household Sync Retry

Design Decisions

  • Use the provided implementation plan and current sync coordinator documentation as the source of truth where they refine the older PRD, especially for running full Household catch-up sync on network reconnect.
  • Keep network awareness behind an app-owned sync adapter so active Household surfaces and tests do not depend on NetInfo directly.
  • Treat React Native AppState as an app-wide platform input to the default sync coordinator factory, not as a Home-owned dependency. Reconnect catch-up sync waits for active app state instead of running while the app is inactive or backgrounded.
  • Add @react-native-community/netinfo because the PRD, plan, and current sync coordinator documentation require it as the production connectivity source.

Deviations From Spec

  • None.

Tradeoffs Considered

  • Reconnect uses the full sync mode rather than push-local-only so the active Household catches up with other Members' changes as well as propagating local rows.
