Implementation Notes: Network-aware Household Sync Retry

Design Decisions

  • Selected @react-native-community/netinfo behind an app-owned network status adapter. It provides connectivity subscriptions, is compatible with Expo SDK 55 through expo install, and had materially higher current npm usage than expo-network during research: roughly 2.1M weekly npm downloads versus roughly 656k for expo-network.
  • Modeled app connectivity as online, offline, and unknown. The adapter treats explicit disconnected or unreachable states as offline, strict internet reachability as online, and ambiguous platform states as unknown.
  • Kept sync orchestration inside the existing Active List provider because a first-class Household sync coordinator has not yet been introduced and the PRD marks building it as out of scope.

Tradeoffs Considered

  • expo-network was more tightly Expo-owned and recently published with SDK 55, but it has lower npm usage and does not fit the subscription-oriented reachability boundary as directly as NetInfo. NetInfo was last published in February 2026 and its repository was active in February 2026, which was maintained enough for this app boundary.
  • The sync retry timer remains installed while Home is open, but known-offline connectivity pauses remote attempts by gating retry execution. This keeps lifecycle cleanup simple while satisfying the no-known-offline-remote-attempt behavior.
