Implementation Notes: Service Refactor Review Fixes

Design Decisions

  • Authorized Active List data sources perform an initial local-only sync pass after mounting so cached offline writes in the local Household store are pushed once fresh credentials are available.
  • The UI and Home data-source layers avoid duplicate Item mutation error logs; ItemService owns add/check failure diagnostics with domain context.
  • HouseholdStore exports a shared execute-only type for ListService, ItemService, and sync fallback callers that only need SQL execution.
  • The server-service import rule now resolves relative import strings against the importing filename so sibling-domain server imports are caught outside allowed server/test contexts.

Deviations From Spec

  • None yet.

Tradeoffs Considered

  • The initial authorized sync may push rows even when no cached offline writes exist, but it keeps the policy simple and bounded to Home's existing push-local-only sync path.
