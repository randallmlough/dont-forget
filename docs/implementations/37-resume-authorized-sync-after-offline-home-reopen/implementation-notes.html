Implementation Notes: Resume Authorized Sync After Offline Home Reopen

Design Decisions

  • Home starts the fresh authorized Household sync coordinator after replacing cached local Home content so local changes saved during offline use can retry without waiting on a separate UI ownership boundary.
  • Cached Household Session content still opens without sync authorization; the cached coordinator is not used to propagate local rows until a fresh authorized Household Session is available.

Deviations From Spec

  • None yet.

Tradeoffs Considered

  • Relying only on Active List mount effects would keep one fewer lifecycle call in Home, but Home already owns cached-to-fresh replacement and cleanup, so starting the fresh coordinator there keeps offline reopen recovery tied to the Household Session authorization decision.
